# Bundled fonts

Latin subsets of these variable fonts are served locally, so every font pair in
Settings → Appearance works with no network. Each is distributed under the SIL
Open Font License 1.1; the corresponding license is in this folder. Characters
outside the subset use the system font fallback.

| File | Family | Source |
| --- | --- | --- |
| inter-latin.woff2 | Inter, weights 100–900 | Google Fonts, Inter v20 |
| bricolage-grotesque-latin.woff2 | Bricolage Grotesque, opsz 12–96, weights 400–800 | Google Fonts |
| nunito-latin.woff2 | Nunito, weights 200–1000 | Google Fonts |
| dm-sans-latin.woff2 | DM Sans, opsz 9–40, weights 300–700 | Google Fonts |
| space-grotesk-latin.woff2 | Space Grotesk, weights 300–700 | Google Fonts |
| fraunces-latin.woff2 | Fraunces, opsz 9–144, weights 400–800 | Google Fonts |
| lora-latin.woff2 | Lora, weights 400–700 | Google Fonts |
| jetbrains-mono-latin.woff2 | JetBrains Mono, weights 100–800 | Google Fonts, JetBrains Mono v24 |

Downloaded from fonts.gstatic.com on 2026-09-22 (Inter, JetBrains Mono) and
2026-10-02 (the rest). Licenses come from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl).
