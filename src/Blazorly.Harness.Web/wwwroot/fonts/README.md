# Bundled fonts

Latin subsets of these variable fonts are served locally. Each is distributed under
the SIL Open Font License 1.1; the corresponding license is included in this folder.
Characters outside the subset use the system font fallback.

| File | Family | Source |
| --- | --- | --- |
| inter-latin.woff2 | Inter, weights 100–900 | Google Fonts, Inter v20 |
| manrope-latin.woff2 | Manrope, weights 200–800 | Google Fonts, Manrope v20 |
| jetbrains-mono-latin.woff2 | JetBrains Mono, weights 100–800 | Google Fonts, JetBrains Mono v24 |

Downloaded from fonts.gstatic.com on 2026-09-22. Licenses come from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl).
