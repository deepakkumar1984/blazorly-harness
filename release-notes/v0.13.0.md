# Blazorly 0.13.0

A reliability release for long-running work and task tracking: background servers start the right way, the task list stays honest through the session, and the plan review modal finally fits big plans.

- **Background servers without the hang.** Starting a server with shell `&` used to wedge the bash call — the backgrounded process held the call's output pipes open, so the agent sat stuck until timeout. Foreground calls now detect that stall, stop the orphaned process tree, and say exactly what to do instead: run servers and watchers with `run_in_background: true` and follow them with `job_output` / `job_kill`. Background jobs also run under the same workspace sandbox as foreground commands instead of silently unconfined.
- **A task list you can trust.** The agent now plans multi-step work up front in `todo_write` and keeps it accurate as it goes — exactly one task in progress, each marked completed the moment it finishes, newly discovered work added instead of done off-list. Nothing is left pending or half-done when the work finishes, and the discipline survives workspace-level custom instructions.
- **A tighter default brief.** The built-in system prompt is rewritten as a sixteen-section engineering charter — correctness, testing with real evidence, security, safe change management — with an explicit completion report (summary, what changed, what was actually verified, risks, next steps).
- **Roomier plan review.** The plan approval modal grows from 1060px to 1400px wide and fills more of the viewport height, with a wider section outline and wrapping titles, so long plans and long headings read without squeezing.
- **Wider swarms.** The swarm fan-out cap rises to 20 parallel workers, with validation updated to match.

## Upgrade notes

- No migration needed. Restart the app to pick up the release; no settings or workspace changes required.
- If you replaced the default system prompt per workspace, your custom text still wins — only the built-in default changed. The task-list and background-run guidance also ship as independent tool sections, so they apply regardless.
- Custom CSS keeps working: no token names changed. The plan review modal only grew (`.plan-review` width/height, `.plan-review-outline` width) plus title wrapping.
