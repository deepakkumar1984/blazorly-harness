# Blazorly 0.10.0

Version visibility, in-app updates, and a leaner prompt: the app now shows its version under the title, checks for and installs updates from Settings, and loads skills on demand instead of injecting the whole catalog every turn.

- Version label below the Blazorly Harness title (sidebar) and hero, with an update pill when a newer release exists.
- Settings → Updates tab: check for new releases and one-click update with log and restart prompt (Windows still needs a manual `blazorly update` after stopping).
- New harness-buckle logo mark in sidebar, hero, and favicon.
- Skills go on demand: new `search_skills` tool plus the existing `skill` loader; the system prompt now carries only the installed count, so prompt size stays flat as skills grow.

## Upgrade notes

- Restart the app to pick up the release. No settings or workspace changes needed.
- Dev builds (`dotnet run`) now report the latest git tag instead of `v0.1.0`.
