# Blazorly 0.9.0

Per-workspace agents, a real default instruction set, grouped tools with a global default, and questions that actually wait for you.

## Per-workspace agent setup

- **⚙ Agent setup** on every workspace row (sidebar switcher): an *Instructions* tab and a *Tools* tab, saved on the workspace in `workspaces.json` — never in global settings.
- Custom instructions replace the configurable instruction body. The fixed identity header (harness name, provider, model, today's date) always stays on top and is not editable.
- The tool allow-list is enforced on every agent published into that workspace: chats already open pick it up on save, new chats and `blazorly run` from that folder get it at creation, and subagents get it too (they do not inherit their parent's scope).
- Placeholders `{{provider}}`, `{{model}}`, `{{cwd}}`, `{{date}}` and `{{weekday}}` interpolate in your text; anything else stays literal instead of failing the request.

## A real default instruction set — and a dated identity

- The built-in instruction body is now a full engineering charter: 21 sections covering mission and accountability, requirements analysis, codebase discovery, planning, architecture, code quality, correctness and error handling, testing, security, performance, data integrity, API standards, dependencies, root-cause analysis, change management, documentation, autonomy, delivery standards and response format. It is the default for new workspaces, for existing workspaces with no override, and for **Reset to default**.
- The fixed identity header now carries today's date, re-read on every request: `Today is Saturday, 2026-09-26 in this machine's local time zone.` `{{date}}` and `{{weekday}}` are available as prompt variables everywhere.
- Cost, stated plainly: the charter is ~5,500 tokens and goes out with every request of every agent (subagents and compaction included). A workspace that wants a leaner prompt replaces the body from ⚙ Agent setup — that is the cheapest trim available.

## Grouped tools, and a default for all workspaces

- The tool picker no longer shows 42 flat checkboxes. Tools render as capability families — files & code, run commands, background jobs, plans/tasks/goals, reminders, helpers & teammates, multi-step routines, web, past sessions, skills, ask-you-questions — plus one row per MCP add-on. A family switches its tools together (they need each other: `job_list` without `job_output` is a half feature) and expands when you want one tool off.
- **Settings → Capabilities** now opens with *Default tools for every workspace*: the same picker, applied to every workspace that has no selection of its own, live chats included on Save. Precedence: workspace selection → global default → every tool. "Select all" stores no restriction at all, so tools added later (MCP servers, plugins) join automatically.

## Questions wait for you

- `ask_user_question` now waits **15 minutes** (was 10) before the assistant continues on its stated defaults.
- Fixed the bug behind "I answered but it used the defaults anyway": when the wait ended, the question card stayed on screen and a late click was silently discarded. The card now disappears the moment the wait ends, and a click that lands too late says so — *"That request expired before your answer landed"* — instead of pretending it was delivered.

## Fixes and hardening

- Tool-scope restrictions are copy-on-write snapshots and reclaim their layer when an agent is disposed, so concurrent schema reads (driver threads vs. UI saves) cannot tear and disposed agents cannot leak scopes.
- User-authored prompt sections interpolate leniently: a stray `{{placeholder}}` is copied through verbatim instead of failing the request with `PROMPT_VARIABLE`. Compaction assembles prompts too, so it is covered.
- Selecting text in a modal and dragging out no longer closes it — backdrop close arms only when the press starts on the backdrop. Applied to all five sidebar modals.
- The Agent setup modal is a fixed-height flex column: only the panel scrolls, so Save/Cancel stay on screen no matter how long the instructions or the tool list get.

## Upgrade notes

- Restart the app to pick up the release. Tool selections changed in ⚙ Agent setup or Settings → Capabilities reach already-open chats on their next request.
- Workspaces with no stored selection inherit the new global default. Saving text or a tool selection you did not change stores *no override*, so your workspaces keep following the defaults as they evolve.
- Small context windows feel the charter's token cost; replace the body per workspace if you need the room.
