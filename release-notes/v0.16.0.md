# Blazorly 0.16.0

You can carry a harness setup from one run to the next, and check it against the stock setup before you keep it. A profile packs instructions, skills, and a few behavioral settings. A comparison runs that profile on the same tasks as the baseline. A refinement round can propose a change, try it, and adopt it only when it holds up. In chat, Compress context summarizes older history and leaves the recent conversation in place.

- **Portable harness profiles.** A profile is a file: instructions, tool guidance, packaged skills and scripts, and a short list of behavioral settings (answer style, the token-saver switches, and compaction). It carries no provider, API key, or permission preset. `blazorly profiles validate` checks a file. `blazorly profiles snapshot` writes one. Built-in names are `baseline`, `compression` (tool-output compression on), and `terse` (terse answers on). `blazorly run --profile <file>` and `blazorly eval --profile <file>` use a profile for that run only. Global settings stay as they are.
- **Compare profiles on the same tasks.** `blazorly eval compare` always includes the pinned baseline, repeats trials (1–10), and writes `comparison.md` plus captured event logs, configuration hashes, token counts, and check results. A candidate that fails a task the baseline passed is not recommended unless you pass `--allow-regressions`. Per-task regressions are listed either way. `--resume` continues a comparison only when the configuration and the captured artifacts still match.
- **Refine, then keep the winner.** `blazorly eval refine` runs a Propose–Probe–Compose round: a bounded editor proposes a change, the task set probes it, and the baseline stays unless the candidate earns the change. The adopted profile is saved as `adopted-profile.json`. Nothing is written into global settings. `--rounds` repeats that round up to 3 times; each later round starts from the best profile so far, has its own 7-call editor cap, and shares the run's token budget. The default is 1. `--equal-budget` repeats the baseline until it has had as many attempts as the round, then reports whether the adopted profile beat the best of those. `--resume` continues an interrupted run in `--out` when the baseline, tasks, route, and round settings match. `--library` turns on reflection and stores only a supported isolated-edit lesson.
- **Lessons stay off until you ask.** `blazorly experience add`, `list`, `show`, and `revoke` record a lesson only when the verdict is `helped` and the lesson points at real events from at least two contrasting runs. Lessons belong to one workspace. A lesson tied to one git revision, provider, or model stays hidden when that context no longer matches. Chat retrieves matching lessons only when `enableHarnessExperience` is true in `settings.json`. Deleting a workspace deletes its lessons. Ordinary chats do not create lessons on their own.
- **Compress context keeps the recent conversation.** The context card has **Compress context**, the same action as `/compact`. It summarizes older history and leaves the newest quarter of the live conversation verbatim, so the next turn still has the recent thread. The summary can run to 2048 tokens and is asked to keep the goal, decisions, paths, errors, and the next steps. The summary model's token usage is stored on the compaction event.
- **Clearer task and agent headers.** Clear task list and hide finished agents are icon buttons. When every delegated agent has settled, the header shows a check.
- **Separate eval suites.** `eval/tasks` is the default suite for `eval`, `eval compare`, and `eval refine`: file and recovery smoke tasks, plus behavior, API, and migration fixtures. `eval/heldout` is a separate suite. Refinement and the default compare path do not load it.

## Upgrade notes

- Chats, settings, and existing installs behave as before until you pass `--profile` or turn experience on. `blazorly update` still replaces the installed archive.
- **`/compact` is milder.** It no longer collapses the session to a single recent node. The newest quarter of the live conversation stays verbatim. Compress context in the context card does the same thing.
- **Experience is off.** Add `"enableHarnessExperience": true` to `settings.json` and restart to retrieve lessons in chat. `harnessExperienceTaskClass` defaults to `"coding"`. There is no lesson-review page and no workspace profile picker in the UI. Pass an adopted profile with `--profile` on `run` or `eval`.
- A profile never edits `settings.json`, and it cannot set the provider, the key, or the permission preset.
- Point `--tasks eval/heldout` at the held-out suite only after a profile is frozen. A default refine or compare does not see those tasks.
- Restart the app to pick up the release.
