# Blazorly 0.12.0

The interface is rebuilt on a new design-token system. Twelve palettes, ten accents, seven type pairs, four text sizes and four corner styles — every surface of the harness repainted on them, and your saved look migrates itself.

- **Twelve palettes instead of six.** Cream, Paper, Mist, Blossom and Sage; Midnight, Graphite, Obsidian, Forest, Ocean, Ember and Terminal. **Match my device** still follows your OS, and Midnight is the fallback if the appearance script cannot run at all.
- **Accent colour is now a choice, not a hex field.** Ten named accents — Iris, Coral, Rose, Sunny, Lime, Mint, Matrix, Sky, Indigo, Mono — each with a light-theme and a dark-theme lightness, plus *Theme default* and any custom colour you like. Buttons, links, highlights, the send key and the brand gradient all follow it.
- **Seven type pairs.** Playful (Bricolage Grotesque + Inter), Clean (Inter), Friendly (Nunito), Techy (Space Grotesk + DM Sans), Editorial (Fraunces + Lora), Mono (JetBrains Mono) and System. The code and terminal font stays its own separate pick. All six new families are bundled for offline use, with their licenses.
- **Text size and corner style.** Compact / Default / Large / Extra large scales the whole interface; Sharp / Soft / Round / Bubbly sets how round every surface reads. A **Reduce motion** switch calms the pulses and transitions.
- **Six quick looks.** Cozy, Focus, Hacker, Sunset, Ocean and Storybook each set palette, accent, type, corners and text size in one click.
- **Rebuilt Appearance page.** Quick looks with palette previews, theme cards that each paint a miniature workspace in their own colours, per-font specimen cards, live preview, and a summary of everything currently applied.
- **Repainted app.** Gradient pill primary buttons, accent-tinted user messages, segmented pill tabs, floating popovers, rounded cards with real shadows, a blurred modal scrim, and one shared focus ring on every field. The reconnect dialog and error bar follow the theme instead of hard-coded white and blue.
- **Custom CSS keeps working.** The token names are unchanged — `--bg`, `--bg-raised`, `--text-dim`, `--accent`, `--radius`, `--shadow-*` and the rest — so a stylesheet written for an earlier version still applies. New knobs (`--accent-soft`, `--accent-softer`, `--brand-gradient`, `--radius-*`) are available if you want them.

## Upgrade notes

- **Your look is kept.** Preferences saved by an earlier version migrate on load: Midnight stays Midnight, Daylight becomes Mist, Evergreen becomes Forest, Dusk becomes Midnight, and Inter/Manrope/Georgia map onto Clean/Friendly/Editorial. An accent colour you chose yourself is preserved exactly — it only becomes a named preset if it is practically identical to one.
- **One visible difference in dark themes.** Accent-filled buttons now pick whichever foreground reads better, so some violet, blue, amber and coral buttons carry near-black text instead of white. Every accent on every palette clears 4.5:1 for its button label.
- **Secondary text is darker on light palettes.** Cream, Paper, Mist, Blossom and Sage gained contrast in their dim and faint levels, which reads better at the small sizes the interface uses.
- Appearance preferences still live only in this browser. Restart the app to pick up the release; no settings or workspace changes needed.
