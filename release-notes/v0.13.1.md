# Blazorly 0.13.1

A small follow-up to 0.13.0. Agents stop narrating hidden context bookkeeping, and the plan approval dialog is actually wide enough to read.

- **No more "Context absorbed".** After a context refresh or a compaction, the agent was opening with "Context absorbed — continuing…", which read as the product talking to itself. It now starts on the next action. The rule is on the identity header, so a workspace that replaced the default charter still gets it. The runtime-context snapshot and the compaction summary say the same thing.
- **Plan review is wide.** 0.13.0 set the approval dialog to 1400px, but the generic modal rule later in the stylesheet won, so the dialog stayed about 620px. The table of contents took 250px of that and the plan was squeezed into the rest. The plan review rule now wins. The dialog is `min(2800px, 96vw)` — twice the 1400px target, still inside the window — and the section outline is 500px.

## Upgrade notes

- Restart the app to pick up the release. No settings or workspace changes required.
- A custom system prompt still replaces only the charter. The "do not announce context" line is on the header, which is not editable, so it applies either way.
- Custom CSS keeps working: no token names changed. The plan review selector is now `.modal.plan-review` (width and height). The outline column is `.plan-review-outline` at 500px.
