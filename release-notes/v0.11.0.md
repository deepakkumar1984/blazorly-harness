# Blazorly 0.11.0

Todo and delegation housekeeping: clear stale task lists, hide settled agent rows, and get honest "still working" answers from subagent and team sends instead of timeouts.

- **Clear the task list.** A `clear` button on the Tasks panel — and passing an empty list to `todo_write` — resets the list; the panel hides until the agent's next snapshot. History stays in the session log; only the latest-wins view resets.
- **Tidy the Agents panel.** Settled delegation rows get a per-row ✕ to hide, and a **clear finished** button hides every settled row at once. Running rows stay visible so live work isn't stranded, and dismissing never touches the child's session.
- **Smarter `subagent_send` / team sends.** When a child is still working after the wait times out, the tool now returns `finish_kind: queued` instead of failing — the message stays queued in the child, so poll `subagent_list` rather than re-sending into the queue.
- **`subagent_list` reports live state.** Entries now carry `running`, `pending`, and `last_active`, so you can tell "still working" from "result ready" before summarizing delegated work.

## Fixes and hardening

- Interrupts landing mid-request now read **aborted** in the delegation panel instead of **error**.
- Duplicate terminal status rows from the monitor/reconciler race are deduplicated.
- Delivery waits are bounded so a queued follow-up can't stretch past the caller's timeout.
